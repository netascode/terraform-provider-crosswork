# Cisco Crosswork Network Controller Provider

Use the Crosswork provider to manage a Cisco Crosswork Network Controller (CNC) cluster through its REST API.

All resources and data sources have been tested with the following releases.

| Platform                     | Version |
| ---------------------------- | ------- |
| Crosswork Network Controller | 7.2.0   |
| Crosswork Network Controller | 7.2.1   |
| TSDN Function pack           | 7.2.1   |

## Requirements

- [Terraform](https://www.terraform.io/downloads.html) >= 1.11

Resources that manage secrets expose them as [write-only arguments](https://developer.hashicorp.com/terraform/language/resources/ephemeral#write-only-arguments) (the `*_wo` attributes), which are only supported in Terraform 1.11 and later.

## Getting Started

The following guides with examples exist to demonstrate the use of the provider:

- [Getting Started](https://registry.terraform.io/providers/CiscoDevNet/crosswork/latest/docs/guides/getting_started)
- [Managing Secrets](https://registry.terraform.io/providers/CiscoDevNet/crosswork/latest/docs/guides/secrets)
- [Manage Multiple Instances](https://registry.terraform.io/providers/CiscoDevNet/crosswork/latest/docs/guides/manage_multiple_instances)

Crosswork limits the number of sessions per user. The provider uses one session per Crosswork instance and logs out when it exits.

## Example Usage

```terraform
provider "crosswork" {
  username = "admin"
  password = "password"
  url      = "https://10.1.1.1"
}
```

## Schema

### Optional

- `allow_existing_on_create` (Boolean) **Experimental (use at your own risk).** Allow existing objects in Crosswork to be managed. If `true`, a POST request that attempts to create an already existing resource will trigger an update instead of failing. This behavior is not guaranteed and may not work for all resources. This can also be set as the CW_ALLOW_EXISTING_ON_CREATE environment variable. Defaults to `false`.
- `device_ready_mode` (String) What a device needs in Crosswork before a resource that names it is created or updated (the Services and Traffic Engineering resources and the Golden Configuration jobs): `none` makes no wait, `synced` waits until the device is synced with NSO, `full` also waits until it is reachable and admin up. With `none` NSO refuses a reference to a device that it does not know yet. This can also be set as the CW_DEVICE_READY_MODE environment variable. Defaults to `synced`.
- `device_ready_timeout` (Number) Longest time in seconds to wait for the devices that a resource names to be ready as `device_ready_mode` says; 0 checks once. This can also be set as the CW_DEVICE_READY_TIMEOUT environment variable. Defaults to `300`.
- `insecure` (Boolean) Allow insecure HTTPS client. This can also be set as the CW_INSECURE environment variable. Defaults to `true`.
- `instances` (Attributes List) This can be used to manage a list of Crosswork instances from a single provider. All instances must use the same credentials. Each resource and data source has an optional attribute named `instance`, which selects an instance by its name from this list. Without `instance`, the default instance is used: the cluster of `url`. (see [below for nested schema](#nestedatt--instances))
- `max_timeout` (Number) Longest time in seconds to wait for the NSO plan of a service after it was written (the Services and Traffic Engineering resources), unless the resource sets its own. This can also be set as the CW_MAX_TIMEOUT environment variable. Defaults to `300`.
- `password` (String, Sensitive) Password for the Crosswork instance. This can also be set as the CW_PASSWORD environment variable.
- `retries` (Number) Number of retries for REST API calls. This can also be set as the CW_RETRIES environment variable. Defaults to `3`.
- `url` (String) URL of the Crosswork instance. This can also be set as the CW_URL environment variable. If it is not set, the URL of the first entry of `instances` is used.
- `username` (String) Username for the Crosswork instance. This can also be set as the CW_USERNAME environment variable.
